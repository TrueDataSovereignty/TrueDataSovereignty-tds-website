TDS Layer · free · browser

Keep personal data out of your AI chats.

TDS Layer masks Swedish ID numbers, e-mail addresses, phone numbers and some names in the chat box on claude.ai, chatgpt.com and gemini.google.com before you send. The AI gets placeholders such as ⟦PERSON_1⟧. It runs on your device.

How it works

You stay in control.

Masks before you send

Pasted text is masked before it lands in the box. For typed text, press the pill or Alt+Shift+M. Send is stopped while the box still holds an identifier it finds. It never sends, clicks or calls a site for you.

Runs on your device

Its code makes no network calls. No account, no tracking, no analytics. Nothing is read on any site until you turn it on.

Stops what it cannot check

Voice input and file uploads are stopped first. If it cannot find the chat box, every send is blocked until the box is back. "Allow once" lets one through.

In this beta

What it finds, and what it does not.

Finds

  • E-mail addresses and phone numbers
  • Swedish personal and organisation numbers
  • VAT numbers, IBANs and card numbers
  • Names in a signature or behind a first.last e-mail address

Does not find yet

  • A name that appears only in running text
  • Places
  • Company names

Read before you use it

The limits, stated plainly.

  • A closed beta in test mode, for invited testers. Please use made-up text only.
  • Detection is not perfect. Always read the masked text before you send.
  • Joining several messages can reveal more than each one alone.
  • Restore is off by default, and works on claude.ai only for now; on chatgpt.com and gemini.google.com TDS Layer masks but does not restore. If you switch it on, the real values go back into the site's page, where the site's own scripts and other extensions can read them.
  • Chrome and Edge only, on three AI chat sites.
  • TDS Layer is not affiliated with Anthropic, OpenAI or Google.
