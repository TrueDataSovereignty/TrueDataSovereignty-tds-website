TDS MCP · documents

Let your AI assistant read files, through the gate.

TDS MCP is a local MCP server for Claude Desktop or any MCP host. Its tools read files from folders you allow, and every result gets the router's decision before the model sees it.

How it works

Masked, widened, or not sent at all.

Only your folders

It reads UTF-8 text files in folders you allow. Anything outside them, network paths, binary files, and secrets and credential files by name (.env, key files, .git) are always refused.

One decision per file

Each result is masked, widened and masked, or replaced by a short note. File names in a folder listing are masked too.

A record of each call

Each tool call writes one line to its own audit log: route, rule and counts only. Not the path, the arguments or the text.

What it does not protect

The limits, stated plainly.

  • An early local version.
  • It protects only what passes through its own tools. What you type into the chat, files you attach by hand and other MCP servers' results go to the model as they are.
  • Text files only: no PDF, Word, images or e-mail yet. Local files only.
  • Widening cannot be undone: the model and its answer see the region and the range.
  • The answers keep the placeholders; this version does not put real values back into them.
